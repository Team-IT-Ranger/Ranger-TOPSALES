# ธีมการ์ด "อินไซต์เย็บด้าย" — คอนเซ็ปต์สำหรับแอปอื่น

สเปกแบบพกพาได้ของธีมการ์ดตัวเลขที่ใช้ใน Ranger TOPSALES: **การ์ดพื้นขาวแบบอินไซต์ + รอยเย็บด้ายรอบขอบใน**
เขียนให้แอปอื่นหยิบไปใช้ได้โดยไม่ต้องรู้จักโค้ดของแอปนี้ — ไม่มีอะไรในนี้ผูกกับ Apps Script,
ชื่อตารางของเรา หรือตัวสร้างการ์ดของเรา

หน้าเดโมที่กดเล่นได้ (สลับเย็บ/ไม่เย็บ · สลับสีด้าย · มีปุ่มคัดลอก CSS):
<https://claude.ai/artifact/Ej4FY7VmAHh25fKsvgxj7a>
(เป็นหน้าส่วนตัวของบัญชีเจ้าของ — ถ้าจะให้ทีมอื่นเปิด ต้องกดแชร์จากเมนู Share ของหน้านั้นก่อน)

ของจริงในแอปนี้อยู่ที่ `frontend-admin/index.html` — ธีมอินไซต์บล็อก `body.theme-insight`
และรอยเย็บอยู่ในบล็อก `body.theme-premium` (ในแอปเราเย็บอยู่กับธีมพรีเมียม) · เอกสารนี้คือ **การรวมสองอย่าง**
เป็นธีมเดียวพร้อมค่าที่ปรับให้เข้ากัน

## 1. ธีมนี้พยายามทำอะไร

| | |
|---|---|
| **อ่านได้ทั้งวัน** | พื้นสว่าง ไม่มีเงา ไม่มีสีจัด — หน้าแดชบอร์ดที่คนเปิดค้างไว้แปดชั่วโมงไม่ควรตะโกน |
| **สีมีความหมาย** | สีไม่ได้เลือกให้สวย แต่ผูกกับ **ประเภทข้อมูล** ชุดเดียวทั้งแอป (ข้อ 3) |
| **รายละเอียดที่ดูตั้งใจ** | รอยเย็บด้ายบางๆ รอบขอบในเป็นรายละเอียดเดียวที่ "เกินหน้าที่" — มีได้ที่เดียวพอ |
| **ตัวเลขเป็นพระเอก** | ตัวเลขใหญ่และเป็นสีประจำประเภท ชื่อการ์ดตัวเล็กสีอ่อน ไม่แย่งความสนใจ |

**สิ่งที่ธีมนี้ไม่ใช่**: การ์ดสีเข้ม การ์ดมีเงาฟุ้ง การ์ดมีไอคอนใหญ่ หรือกราฟในการ์ด
ถ้าอยากได้แบบนั้นนี่เป็นธีมผิดตัว

## 2. หลักคิดสี่ข้อ (ข้อแรกสำคัญที่สุด)

1. **พื้นหน้าต้องเหลื่อมกับการ์ด** — พื้นเทาอ่อนมาก `#F4F5F8` + การ์ดขาวสนิท `#FFFFFF`
   การ์ดจึงลอยขึ้นมาเองโดยไม่ต้องพึ่งเงา · ครั้งแรกเราตั้งพื้นเป็นขาวเท่าการ์ด ผลคือการ์ดจมหายไปกับพื้น
   เหลือแต่เส้นขอบบางๆ ให้เดา — **ความเหลื่อมนี้คือตัวธีม ไม่ใช่รายละเอียดปลีกย่อย**
2. **สีเข้าการ์ดผ่านตัวแปรสองตัวเท่านั้น** (`--k-hue`, `--k-tint`) คลาสประเภทข้อมูลประกาศได้แค่ตัวแปร
   **ห้ามลงสีเอง** ไม่งั้นมันจะไปทับรูปทรงของธีมอื่นที่ใช้ตัวแปรชุดเดียวกัน
3. **รอยเย็บเป็นแผ่นลอยทับ ไม่ใช่ `border` ของการ์ด** — border กินพื้นที่จริง เนื้อข้างในเล็กลง
   และการ์ดที่มี/ไม่มีด้ายจะสูงไม่เท่ากัน
4. **เนื้อหาไม่เต็มจอ** — คอลัมน์กลางจอ แต่ต้องกว้างพอให้แถวการ์ดไม่ตกบรรทัด (สูตรข้อ 6)

## 3. สัญญาของโทเคน — ทำตารางสีก่อนทำการ์ด

ทำตารางนี้ให้เสร็จก่อนลงมือทำการ์ดใบแรก ไม่ใช่เลือกสีตอนทำการ์ดแต่ละใบ
(ไม่งั้นหกเดือนถัดไปจะได้การ์ด "จำนวนเอกสาร" สามใบในแอปเดียวกัน คนละสี)

| ประเภทข้อมูล | คลาส | `--k-hue` (จุด/ตัวเลข) | `--k-tint` (พื้นอ่อน) |
|---|---|---|---|
| ยอดขาย · รายได้ | `.k-sales` | `#1F8A5F` เขียว | `#DFF3E9` |
| หนี้ · เกินกำหนด · ของเสีย | `.k-debt` | `#C4443C` แดง | `#FDE7E5` |
| งานค้าง · รออนุมัติ | `.k-pending` | `#B4741A` เหลืองอำพัน | `#FCEEDA` |
| จำนวนเอกสาร · รายการ | `.k-doc` | `#2B63D9` ฟ้า | `#F1F6FE` |
| คน · ผู้ใช้ · ลูกค้า | `.k-people` | `#6245C9` ม่วง | `#EAE5FB` |
| สต็อก · คลัง | `.k-stock` | `#0E7C86` เขียวอมฟ้า | `#DDF0F2` |
| ส่งเสริมการขาย | `.k-promo` | `#B4457E` ชมพูเข้ม | `#FBE7F1` |

```css
/* ★ คลาสสีประกาศแต่ตัวแปร ไม่ลงสีเอง */
.kpi.k-sales  { --k-hue:var(--green);  --k-tint:var(--green-soft); }
.kpi.k-debt   { --k-hue:var(--red);    --k-tint:var(--red-soft); }
/* … */
```

**เมตริกเดียวที่ถูกหารเป็นหลายใบ** (ยอดขายแยกตามพนักงาน, ยอดแยกตามสาขา) ใช้ชุดเรียง
`.k-s1 … .k-s6` วนสีไปตามลำดับ — ที่นั่นสีทำหน้าที่ **แยกใบออกจากกัน** อย่างเดียว
ไม่ต้องหาความหมายให้แต่ละสี

ธีมอินไซต์ใช้แค่ `--k-hue` บนการ์ด (จุด + ตัวเลข) ส่วน `--k-tint` ยังต้องประกาศไว้ให้ครบ
เพราะธีมอื่น (และ hover/ป้ายสถานะ) ใช้มัน

## 4. โครงของการ์ด

สามชั้นเรียงบนลงล่าง ทุกการ์ดเหมือนกันหมด:

```
● ชื่อการ์ด            ← จุดสี 7px (= ประเภทข้อมูล) + ชื่อสีหมึกอ่อน 12.5px
฿128,450              ← ตัวเลข 27px ตัวหนา สีเดียวกับจุด บีบช่องไฟ -.02em
24 บิล · ออกใบแล้ว     ← คำอธิบาย 12px สีหมึกอ่อน บอกที่มา/เงื่อนไขของตัวเลข
```

```css
body.theme-insight{ --ground:#F4F5F8; }            /* พื้นหน้า เหลื่อมกับการ์ด */

body.theme-insight .kpi-row{ gap:16px; }
body.theme-insight .kpi-row .kpi{
  background:#fff; border:1px solid #E6E9EF; border-top:1px solid #E6E9EF;
  border-radius:12px; padding:15px 17px; box-shadow:none; }

/* ชื่อการ์ดมีจุดสีนำหน้า — แทนแถบสีด้านบนของธีมเดิม */
body.theme-insight .kpi .lbl{
  display:flex; align-items:center; gap:7px; color:var(--ink-soft); margin-bottom:8px; }
body.theme-insight .kpi .lbl::before{
  content:''; width:7px; height:7px; border-radius:50%; flex:0 0 auto;
  background:var(--k-hue, var(--ink-faint)); }

body.theme-insight .kpi .val{
  color:var(--k-hue, var(--ink)); font-size:27px; letter-spacing:-.02em; }
body.theme-insight .kpi .sub{ color:var(--ink-soft); }

/* แผ่น/ฟอร์ม/ตาราง: เส้นบางเส้นเดียว ไม่มีเงา ให้ทั้งหน้าดูเป็นกระดาษแผ่นเดียว */
body.theme-insight .panel, body.theme-insight .form-card{
  box-shadow:none; border-color:#E6E9EF; }
```

- `border-top` เขียนซ้ำโดยตั้งใจ — ธีมเดิมของเราใช้แถบสีหนา 3px ด้านบน ธีมนี้ต้อง **ลบมันทิ้งอย่างชัดเจน**
  ไม่ใช่หวังว่าจะไม่มีใครตั้งไว้
- ตัวเลขที่เรียงเป็นคอลัมน์ให้ใส่ `font-variant-numeric:tabular-nums` หลักจะตรงกัน
- **ทุก `--k-*` ต้องมี fallback** (`var(--k-hue, var(--ink))`) การ์ดที่ไม่ได้ติดคลาสสีต้องยังอ่านได้

## 5. สูตรรอยเย็บ

ด้ายเส้นเดียว 1px เส้นประ ห่างจากขอบ 2.5px **และรัศมีลดเท่าระยะที่ขยับเข้ามา**

```css
/* รอยเย็บด้าย — แผ่นลอยทับ ไม่ใช่ border ของการ์ด */
body.theme-insight .kpi-row .kpi{ position:relative; }
body.theme-insight .kpi-row .kpi::after{
  content:''; position:absolute;
  inset:2.5px;                 /* ชิดขอบนอกแบบหมิ่นๆ */
  border-radius:9.5px;         /* = รัศมีการ์ด 12 − inset 2.5 */
  pointer-events:none;         /* การ์ดกดได้ ด้ายต้องไม่บัง */
  border:1px dashed var(--k-hue, var(--ink-faint));
  opacity:.42; }               /* บนพื้นขาว .42 · บนพื้นมืด .55 */

/* เย็บรอบปุ่ม: ::before เพราะ ::after เป็นวงหมุนตอนรอเซิร์ฟเวอร์ */
body.theme-insight .btn{ position:relative; }
body.theme-insight .btn:not(.btn-ghost)::before{
  content:''; position:absolute; inset:2px; pointer-events:none;
  border-radius:calc(var(--r-ctl) - 2px);
  border:1px dashed currentColor; opacity:.4; }

/* เย็บรอบ "นอก" แถบเลือก — ข้างในมีปุ่มเต็มพื้นที่อยู่แล้ว */
body.theme-insight .segtog{ position:relative; margin:6px; }   /* 3px วงด้าย + 3px หายใจ */
body.theme-insight .segtog::after{
  content:''; position:absolute; inset:-3px; border-radius:999px;
  pointer-events:none; border:1px dashed var(--ink-faint); opacity:.8; }
```

**สีด้ายเลือกได้สองทาง** — `--k-hue` (สีของการ์ดวนกลับมาอีกชั้น ดูมีชีวิตกว่า) หรือ `--ink-faint`
(เทากลาง เงียบที่สุด เหมาะถ้าในหน้ามีสีเยอะอยู่แล้ว) · ในแอปของเราเลือกตามพื้น: **กรอบสีเข้มใช้ด้ายสีอ่อน
(`--k-tint`) · พื้นสว่างใช้ด้ายเข้มกว่าพื้น · ปุ่มใช้ `currentColor`** จะได้ไม่ต้องเขียนกฎแยกต่อสีปุ่ม

### หกกับดักที่เราเหยียบมาแล้ว

1. **รัศมีไม่ลดตาม inset** → มุมของด้ายโค้งคนละองศากับมุมการ์ด เห็นเป็นเส้นเบี้ยวที่มุมทั้งสี่
2. **ใช้ `border` จริงแทนแผ่นลอย** → เส้นกินพื้นที่ เนื้อข้างในเล็กลง การ์ดสูงไม่เท่ากัน
3. **ลืม `pointer-events:none`** → การ์ด/ปุ่มที่กดได้กดไม่ติด โดยไม่มีอะไรฟ้อง
4. **สีด้ายผิดฝั่งพื้น** → ด้ายเข้มบนพื้นเข้ม/อ่อนบนพื้นอ่อน = หายไปเลย หรือกลายเป็นขอบสกปรก
5. **เย็บวงนอกแล้วไม่เว้นที่** → วงด้ายไปพาดทับข้อความที่อยู่ติดกัน (เราเจอกับคำอธิบายใต้ปุ่มสลับมุมมอง)
   · ใส่ `margin` เท่าระยะที่ล้นออกไป **ที่ตัวควบคุมเอง** และ **เท่ากันทุกด้าน** ไม่ใช่ไล่เพิ่มระยะให้ของข้างเคียงทีละจุด
   (ใส่เฉพาะด้านล่างจะทำให้แถบทั้งแถบเยื้องขึ้น 2-3px)
6. **ปรับความหนาแทนความทึบ** → 2px อ่านเป็นกรอบหนา ไม่ใช่รอยเย็บ · เริ่มที่ **1px แล้วปรับ `opacity`**
   (ของเราขึ้นจาก .72 → .85 บนพื้นเข้ม เพราะเส้นบางบนพื้นเข้มจางกว่าที่คิด)

### ที่ควรเย็บ / ไม่ควรเย็บ

- **เย็บ**: การ์ดตัวเลข · ปุ่มที่มีพื้นหรือขอบ · แถบเลือก (segmented) · หัวคอลัมน์กระดาน
- **ไม่เย็บ**: ปุ่มไร้ขอบไร้พื้น (`.btn-ghost` — เย็บแล้วมันกลายเป็นปุ่มมีกรอบ ผิดความตั้งใจ) ·
  แถวในตาราง (เย็บทุกแถว = ลายผ้า อ่านตัวเลขไม่ออก) · เอกสารสำหรับพิมพ์ (เส้นประเปลืองหมึกและ
  สแกนออกมาเป็นจุดๆ)

## 6. ความกว้างของคอลัมน์

คิดจากแถวการ์ดที่ยาวที่สุดในแอป ไม่ใช่เลือกเลขกลมๆ:

> **จำนวนการ์ด × ความกว้างต่ำสุด + ช่องไฟ × (จำนวน − 1) + ขอบในของหน้า**

ของเรา: `6 × 190 + 16 × 5 + 64 = 1,284px` → ตั้ง `max-width:1320px`
เคยตั้ง 1,180 แล้วการ์ดใบที่หกตกบรรทัดทันทีบนจอ 1366px

```css
body.theme-insight main.content{ max-width:1320px; margin:0 auto; }
```

ถ้าแอปมีธีมเต็มจออยู่แล้ว **เก็บธีมเต็มจอไว้เป็นค่าเริ่มต้น** — คนที่ไม่ได้เลือกธีมจะไม่เจออะไรเปลี่ยน

## 7. ต่อเข้ากับแอป (ทำให้เป็นตัวเลือก ไม่ใช่ยัดเปลี่ยนให้ทุกคน)

**ทุกกฎของธีมขึ้นต้นด้วย `body.theme-<ชื่อ>` เสมอ ไม่มีกฎไหนอยู่ลอยๆ** — ถอดคลาสออกแล้วต้องกลับเป็น
หน้าตาเดิมทันทีโดยไม่ต้องแก้ markup หรือตัวสร้างการ์ดเลย

```js
/* เพิ่มธีมใหม่ = เพิ่มคีย์เดียวที่นี่ + เขียน CSS ใต้ body.theme-<คีย์> + เพิ่มปุ่มในแถบเลือก
   ชื่อคลาสผูกกับคีย์ตรงๆ จะได้ไม่มีตารางแปลงชื่อซ้อนอีกชั้นให้หลุดกัน */
const THEMES = { classic:'คลาสสิก', insight:'อินไซต์' };

function currentTheme(){
  for (const k in THEMES)
    if (k !== 'classic' && document.body.classList.contains('theme-' + k)) return k;
  return 'classic';
}
function applyTheme(name){
  if (!THEMES[name]) name = 'classic';
  Object.keys(THEMES).forEach(k =>
    document.body.classList.toggle('theme-' + k, k !== 'classic' && k === name));
  segSync('theme-seg', name);
}
function setTheme(name){
  if (!THEMES[name] || name === currentTheme()) return;
  try { localStorage.setItem(LS_THEME, name); } catch (e) {}   // ต่อเครื่อง ไม่ผูกบัญชี
  applyTheme(name);
}
(function initTheme(){
  let saved = 'classic';
  try { const v = localStorage.getItem(LS_THEME); if (THEMES[v]) saved = v; } catch (e) {}
  applyTheme(saved);        // เรียกก่อนวาดหน้า ไม่งั้นเห็นธีมเดิมแวบหนึ่ง
})();
```

- **ค่าเริ่มต้นคือธีมเดิมของแอป** เครื่องใหม่/ล้างแคชต้องได้หน้าตาเดิมเสมอ
- เก็บค่าไว้ **ต่อเครื่อง** (localStorage) ไม่ผูกบัญชี — คนละเครื่องชอบคนละแบบได้ และอ่าน/เขียนต้อง `try/catch`
- **โครง HTML เหมือนกันทุกธีม** ถ้าธีมหนึ่งต้องการกล่องห่อตัวเลขเพิ่ม ให้ใส่กล่องนั้นไว้ตลอดแล้วธีมที่ไม่ใช้
  ตั้งเป็น `display:contents` — ตัวสร้างการ์ดจะได้ไม่ต้องรู้ว่าตอนนี้ใช้ธีมอะไร
- **ใส่คลาสทรงที่ "แถว" ไม่ใช่ที่การ์ดแต่ละใบ** (`.kpi-row.kpi-badges`) หน้าอื่นที่ใช้แถวการ์ดเหมือนกัน
  จะไม่เปลี่ยนตามโดยไม่ได้ขอ
- **ระวังน้ำหนักของกฎ**: ถ้าไฟล์มีกฎ `.kpi{border-top:…}` อยู่ท้ายไฟล์ กฎธีมที่เขียนเป็น `.kpi` เฉยๆ
  (น้ำหนักเท่ากันแต่อยู่ก่อน) จะถูกทับ · เขียนเป็น `.kpi-row .kpi` ขึ้นไป (เรื่องนี้กินเวลาเราไปรอบหนึ่ง)

## 8. ธีมมืด

ธีมนี้ออกแบบมาสำหรับพื้นสว่าง ถ้าแอปปลายทางมีธีมมืด ต้องกำหนดใหม่ให้ครบ **ทุกตัว**
ไม่ใช่กลับขาวเป็นดำแล้วจบ:

| โทเคน | สว่าง | มืด |
|---|---|---|
| พื้นหน้า | `#F4F5F8` | `#0E1421` |
| การ์ด | `#FFFFFF` | `#19212F` |
| เส้นขอบ | `#E6E9EF` | `#2A3446` |
| สีประจำประเภท | เข้ม (`#1F8A5F`) | **สว่างขึ้น** (`#3FB383`) |
| พื้นอ่อน (tint) | อ่อน (`#DFF3E9`) | **มืดลง** (`#15392C`) |
| ความทึบของด้าย | `.42` | `.55` |

ความเหลื่อมพื้น↔การ์ดต้องยังเห็นในธีมมืดด้วย (การ์ดสว่างกว่าพื้นเล็กน้อย) — เป็นหลักข้อ 1 ตัวเดียวกัน
