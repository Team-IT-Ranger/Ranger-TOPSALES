เป้าเปิดใช้จริง 1 ต.ค. 2569
นำร่อง 1–2 ตัวแทนจำหน่าย

ข้อมูลไหลจากบริษัทเจ้าของสินค้าลงสู่ตัวแทนจำหน่ายแต่ละราย ผ่านคนขายหน้างาน แล้วไหลกลับขึ้นมาเป็นยอดขาย/สต็อกจริง — พร้อมส่งต่อเข้าโปรแกรมบัญชี Express ของแต่ละตัวแทน

ข้อมูลตั้งค่า — ไหลลง ข้อมูลหน้างาน — ไหลขึ้น เชื่อมไฟล์ Express เฟสถัดไป

2 แอปที่ต้องสร้าง

  • Mobile App — พนักงานขาย ใช้งานง่ายบนมือถือ
  • Admin App — บริหารเต็มรูปแบบ บนคอมพิวเตอร์
  • Admin แบ่ง 2 สิทธิ์: ตัวแทน / บริษัทเจ้าของสินค้า

Promotion Engine

  • ลด % หรือ บาท/หน่วย (ชิ้น·แพ็ค·ลัง)
  • ของแถมเมื่อซื้อถึงจำนวนที่กำหนด คละกลุ่มได้
  • ผูกกลุ่มร้านค้า / กลุ่มสินค้า / ช่วงเวลา
  • บริษัทเจ้าของสินค้าคุมทั้งหมดจากส่วนกลาง

เชื่อม Express (ไฟล์)

  • ลูกค้า · สินค้า · ซื้อเข้า
  • รายการขาย · เบิกจ่ายสินค้า
  • การจัดส่ง · การเก็บเงิน

Tech Stack เฟส 1

Google Apps Script + Google Sheets + GitHub Pages (Admin) + Vercel (Mobile)

ยังไม่ใช้ Cloud Database — เตรียมโครงสร้างรองรับไว้สำหรับเฟสถัดไป
