# ใครทำอะไรอยู่

ไฟล์นี้ตอบคำถามเดียว: **ตอนนี้จับอะไรได้บ้างโดยไม่ชนกับอีกคน**
กติกาเต็มอยู่ใน [CLAUDE.md](../CLAUDE.md) หัวข้อ "ทำงานสองคน" — ที่นี่เก็บแค่สถานะ ณ ตอนนี้

**วิธีใช้**
- เริ่ม session: `git pull` แล้วอ่านไฟล์นี้ก่อนลงมือ
- จับ/ปล่อยกุญแจ หรือเปลี่ยนงาน: แก้**เฉพาะบรรทัดของตัวเอง** แล้ว commit ไปกับงานนั้นเลย ไม่ต้องคอมมิตแยก
- **★ ใส่วันที่ทุกครั้งที่แก้** — บรรทัดที่เก่ากว่า **2 วัน ถือว่าปล่อยแล้ว** หยิบไปใช้ได้เลยไม่ต้องรอ
  (คนลืมปล่อยกุญแจเป็นเรื่องปกติ ถ้าไม่มีข้อนี้ไฟล์จะกลายเป็นตัวล็อกงานถาวรแทนที่จะช่วย)
- **อย่าจัดระเบียบ/เรียงใหม่ทั้งไฟล์** ตอนที่อีกคนกำลังทำงาน — แก้ทีละบรรทัดเท่านั้น conflict จะได้แก้ง่าย

- **ถือยาว** — `index.html` เป็นของเลน frontend ตามการแบ่งงาน ไม่ใช่การจองชั่วคราว
  **กฎ "เก่ากว่า 2 วันถือว่าปล่อย" ไม่ใช้กับแถวนี้** ย้ายมือได้เมื่อตกลงกันเท่านั้น
- **ถือสั้น** — `clasp push` กับ "แก้ข้อมูลเป็นชุด" จับตอนจะทำ ปล่อยทันทีที่เสร็จ
  สองแถวนี้แหละที่กฎ 2 วันมีไว้กัน (ลืมปล่อยแล้วอีกคนติดค้าง)
