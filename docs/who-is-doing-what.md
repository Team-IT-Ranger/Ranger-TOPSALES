# ใครทำอะไรอยู่

ไฟล์นี้ตอบคำถามเดียว: **ตอนนี้จับอะไรได้บ้างโดยไม่ชนกับอีกคน**
กติกาเต็มอยู่ใน [CLAUDE.md](../CLAUDE.md) หัวข้อ "ทำงานสองคน" — ที่นี่เก็บแค่สถานะ ณ ตอนนี้

**วิธีใช้**
- เริ่ม session: `git pull` แล้วอ่านไฟล์นี้ก่อนลงมือ
- จับ/ปล่อยกุญแจ หรือเปลี่ยนงาน: แก้**เฉพาะบรรทัดของตัวเอง** แล้ว commit ไปกับงานนั้นเลย ไม่ต้องคอมมิตแยก
- **★ ใส่วันที่ทุกครั้งที่แก้** — บรรทัดที่เก่ากว่า **2 วัน ถือว่าปล่อยแล้ว** หยิบไปใช้ได้เลยไม่ต้องรอ
  (คนลืมปล่อยกุญแจเป็นเรื่องปกติ ถ้าไม่มีข้อนี้ไฟล์จะกลายเป็นตัวล็อกงานถาวรแทนที่จะช่วย)
- **อย่าจัดระเบียบ/เรียงใหม่ทั้งไฟล์** ตอนที่อีกคนกำลังทำงาน — แก้ทีละบรรทัดเท่านั้น conflict จะได้แก้ง่าย

## กุญแจ — ของที่ถือได้ทีละคน

| กุญแจ | ใครถือ | ตั้งแต่ | ทำไมต้องล็อก |
|---|---|---|---|
| `frontend-admin/index.html` | เลน frontend | 2026-09-28 | 6,078 บรรทัด งาน UI ทุกชิ้นลงไฟล์นี้ — สองคนแก้พร้อมกัน merge นานกว่าทำงาน |
| `clasp push` ขึ้น UAT | — ว่าง | — | โปรเจกต์เดียว Sheet เดียว · push ทับกันได้ · **ห้าม push ระหว่างที่อีกคนกำลังเทสต์** |
| แก้ข้อมูลเป็นชุดบน UAT | — ว่าง | — | `applyCustomerBulkAssign`, `migrate*`, e2e ที่สร้างตัวแทนทิ้งไว้ — ทำตอนอีกคนดูราคาอยู่ ผลจะอธิบายไม่ได้ |

จับกุญแจ = เขียนชื่อเลนกับวันที่ · ปล่อย = เปลี่ยนกลับเป็น `— ว่าง`

กุญแจมีสองแบบ อย่าปนกัน:
- **ถือยาว** — `index.html` เป็นของเลน frontend ตามการแบ่งงาน ไม่ใช่การจองชั่วคราว
  **กฎ "เก่ากว่า 2 วันถือว่าปล่อย" ไม่ใช้กับแถวนี้** ย้ายมือได้เมื่อตกลงกันเท่านั้น
- **ถือสั้น** — `clasp push` กับ "แก้ข้อมูลเป็นชุด" จับตอนจะทำ ปล่อยทันทีที่เสร็จ
  สองแถวนี้แหละที่กฎ 2 วันมีไว้กัน (ลืมปล่อยแล้วอีกคนติดค้าง)

## คิวงานถัดไป

รายการเต็มอยู่ที่ CLAUDE.md หัวข้อ "Pending / not started" — ที่นี่เก็บเฉพาะตัวที่**จองไว้แล้วหรือกำลังจะหยิบ**
เพื่อไม่ให้มีคิวงานสองที่แล้วไม่ตรงกัน

| งาน | เลน | สถานะ |
|---|---|---|
| เก็บตำแหน่ง/บทบาทใน `order_status_log` (guide 1.6) | backend | ✅ เสร็จแล้ว (2026-09-28, `75bf931`) |
| ยอดจอง reserved (guide 1.3) | backend | ✅ backend/สคีมาเสร็จแล้ว (2026-09-28, `9468540`) — เหลือหน้าจอโชว์ตัวเลข reserved/available ที่หน้าคลังสินค้า (ข้อมูลพร้อมจาก `listWarehouseStock` แล้ว) |
| โชว์คอลัมน์ reserved/available ที่หน้าคลังสินค้า | frontend | ว่าง — งานเล็ก ข้อมูลพร้อมแล้ว แค่เพิ่มคอลัมน์ในตารางที่มีอยู่ |
| แก้ไข/ยกเลิกใบรับของ (GR) หลังลงบัญชีแล้ว | backend | ว่าง |
| รายงานการขาย 1.8.1 / 1.8.2 / 1.8.3 | ทั้งสอง | ว่าง — backend ทำ query ก่อน แล้วส่งต่อหน้าจอ |
