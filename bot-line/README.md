### หน้าตาการ์ดของคงเหลือ

**2 คอลัมน์: `รหัสสินค้า` | `คลัง + รถ = รวม`** (เจ้าของระบบสั่ง 21 ต.ค. 2026 หลังทดสอบบนมือถือจริง)
- ของเดิม 4 คอลัมน์ (ชื่อสินค้า · คลัง · รถ · รวม) — ชื่อสินค้ายาวกินที่จนตัวเลขเบียดกัน
- **รหัสสินค้ามาก่อน** เพราะสั้นและเป็นตัวที่คนใช้สั่งของจริง · ชื่อสินค้าไม่อยู่ในการ์ดแล้ว
- **ตัวเลขยุบเหลือช่องเดียวแต่ไม่ทิ้งข้อมูล** — เขียน `10.5 + 3 = 13.5` ซึ่งอ่านได้ในตัวเองว่าตัวไหนคืออะไร
  ไม่ต้องพึ่งหัวตาราง · ยอดรวมเป็น span สีฟ้าตัวหนา ตัวแยกเป็นสีอ่อน (ตาจับ "รวม" ได้ก่อน)
- `*` นำหน้ารหัส = ยังไม่ยืนยันขนาดบรรจุ (ตัวเลขแถวนั้นเป็นชิ้น) · แถวยอดรวมตัดบรรทัดได้เพราะยาวกว่าแถวข้อมูล
